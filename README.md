# Cybersecurity Awareness Lab

An interactive cybersecurity awareness platform designed to help users learn how to identify common online threats through practical simulations and decision-based scenarios.

## Features

- Interactive cybersecurity awareness scenarios
- Fake SMS phishing / smishing simulation
- Email phishing awareness
- Social engineering scenarios
- Scam identification exercises
- Interactive awareness decisions
- Cybersecurity awareness quiz
- Warning signs and safe-response guidance
- Beginner-friendly educational content

## Purpose

The Cybersecurity Awareness Lab is designed for cybersecurity education, awareness training and demonstrations.

All simulations are created for educational purposes. Examples such as suspicious links, messages and account alerts are fictional and should not be used against real systems or individuals.
